# 🌕 ECOLOR Smart Moon Lamp – Web Bluetooth Controller

Since the official **Ecolor Life** app was removed from the App Store and Google Play, this free, open-source web controller brings back full color, brightness, and 4-zone gradient controls directly in your browser — no APK sideloading or account required.

### 🔗 Live Web App
👉 **[Open ECOLOR Moon Lamp Controller]([https://github.io](https://klara-clova.github.io/ecolor-lamp./)**

### 📱 How to Use
* **iPhone / iPad (iOS):** Open the link above in the free **[Bluefy – Web BLE Browser](https://apple.com)** app (Safari does not support Web Bluetooth).
* **Android:** Open the link directly in **Google Chrome** (no APK installation needed).
* **Windows / Mac:** Open the link in **Google Chrome** or **Microsoft Edge** (requires Bluetooth).

### 💡 Troubleshooting
* If the lamp does not appear or fails to connect, unplug it for 5 seconds or **hold the Power touch button while rapidly tapping the "My Color" button until the lamp flashes purple** to reset its Bluetooth module.
